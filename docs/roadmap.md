# Roadmap

## Phase 1

Service skeleton, Docker Compose, health checks, database migrations, seed data, shared schemas, event bus, and frontend shell.

## Phase 2

Phaser map, room click zones, generated RPG-style placeholder employee sprites, employee popups, room popups, and activity feed.

Visual life and atmosphere direction lives in `docs/visual-life-atmosphere-blueprint.md`.

## Phase 3

Simulation tick, employee state machine, mood/fatigue/hunger/stamina drift, basic task progress, and persisted simulation state.

## Phase 4

Read-only system monitor stats converted into normalized infrastructure events.

## Phase 5

Manager reporting, Boss console summaries, alerts, department reports, persisted intercom text, acknowledgements, and generated follow-up tasks.

## Phase 6

Template AI summaries, employee dialogue, suggestions, complaints, and manager briefings.

## Phase 7

Ollama/local LLM support, richer memory, analytics, reverse proxy, and optional real integrations.
