# Floorplan

The MVP map is a top-down placeholder facility using data-driven room records.

Rooms include:

- Boss Office
- Operations Manager Office
- Cultivation Manager Office
- Meeting Room
- Security Office
- Clone Room
- Mother Room
- Grow Room 1
- Grow Room 2
- Soil/Nutrition Prep
- Processing/Trim Room
- Packaging Room
- Extraction Lab
- Break Room/Kitchen
- Bathroom
- R&D Lab
- R&D Test Room
- Sales Office
- Logistics Warehouse
- Loading Dock
- Storage

Room positions, sizes, cleanliness, departments, and system mappings are seed/config records and should remain data-driven.
